## 作るもの 
- 割り勘や買い物の合計など、日々のちょっとした計算に使う電卓 
- パソコンでもスマホでも使えるようにする 
- JavaScriptで画面を動かす基礎のお題です

## 必要な機能 
- 数字、小数点、＋、−、×、÷、＝、クリアのボタン 
- 計算は押した順に行う（「2 + 3 × 4 ＝」は 20 になる。掛け算を先にする電卓にはしない） 
- キーボードでも入力できる（数字、小数点、＋、−、* で掛け算、/ で割り算、Enter で計算、Esc でクリア） 
- ＝で答えが出るたびに、その計算を履歴に1行で追加する（例：2 + 3 × 4 = 20）。新しいものを上にする 
- 入力できる数字は1回に12桁までにする（小数点は数えない） 
- 答えは小数第8位までで丸めて表示し、末尾の0は出さない。答えの整数の部分が12桁を超えたら「桁数が多すぎます」と表示する 
- ＝で答えが出た後に数字を押したら新しい計算を始め、演算子を押したらその答えに続けて計算する 
- 文字列を式として実行する eval は使わない

## できたと言える状態 
- 0.1 + 0.2 の答えが 0.3 と表示される 
- 1.1 × 3 の答えが 3.3 と表示される 
- 1 ÷ 3 の答えが 0.33333333 と表示される 
- 2 + 3 × 4 の答えが 20 と表示される 
- 0で割ると「0では割れません」などのメッセージが出て、Infinity や NaN は表示されない。このとき履歴は増えない 
- 13桁目の数字を押しても、入力が増えない 
- ＝の後に数字を押すと新しい計算が始まり、＋を押すと答えに続けて計算できる 
- キーボードの * / Enter Esc が、画面のボタンと同じように動く 
- ＝で答えが出るたびに、履歴が1行増える
